Original test board made for Dutchman Electronics. Released under CC0 1.0 (public domain): https://creativecommons.org/publicdomain/zero/1.0/

The board holds one font file made by others, under the license in LICENSE-DejaVu.txt (DejaVu Sans Mono, Bitstream Vera license): the embedded font is not CC0, everything else is.

k10-all-features: the KiCad twin of the Altium all-features board, one board with every feature the KiCad reader handles. When the reader learns something new, add it to this board, to its build in fixtures/kicad/build_k10_boards.py and to crates/kicad-pcb/tests/all_features.rs. A note the board still raises is listed in that file's only_the_known_gaps test.

Made with KiCad 10.0.8 (file version 20260206) by fixtures/kicad/build_k10_boards.py, then:
- fixtures/kicad/fill_zones.py (KiCad fills the zone);
- add_stackup.py with stackup-all-features.sexp (the stack-up table);
- add_pad_arcs.py with 1 (the arc of pad 8);
- embed_fonts.py "TrueType 789=DejaVu Sans Mono" (KiCad embeds the font);
- add_text_vars.py PCB_NUMBER=DN-0100, which writes k10-all-features.kicad_pro.

Every number below was read back with KiCad's own scripting. KiCad shows coordinates in millimeters with Y pointing down; the board's top-left corner is at page position (100, 100), and every number below is relative to that corner (so add 100 to x and y for the page position). The reader gives Y up: model x = 100 + X, model y = -(100 + Y).
