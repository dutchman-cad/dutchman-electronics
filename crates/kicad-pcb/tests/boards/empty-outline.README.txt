empty-outline: a 50 mm x 30 mm rectangle, two copper layers, 1.6 mm thick, nothing else.

Made with KiCad 9.0.9 (file version 20241229) by fixtures/kicad/build_boards.py. KiCad shows coordinates in millimeters with Y pointing down; the board's top-left corner is at page position (100, 100), and every number below is relative to that corner (so add 100 to x and y for the page position). The reader gives Y up: model x = 100 + X, model y = -(100 + Y).

- Edge.Cuts: one rectangle (gr_rect), corners (0, 0) and (50, 30), line width 0.1.
- Thickness: 1.6 (general thickness; the file has no stack-up table).
- Solder mask: pad_to_mask_clearance 0 (the mask opening is as big as the pad).
- Layers: F.Cu and B.Cu copper, F/B silkscreen, solder mask and paste, Edge.Cuts and the other KiCad default layers.
