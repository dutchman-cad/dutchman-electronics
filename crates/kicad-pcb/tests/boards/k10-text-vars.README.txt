Original test board made for Dutchman Electronics. Released under CC0 1.0 (public domain): https://creativecommons.org/publicdomain/zero/1.0/

k10-text-vars: texts that use KiCad's text variables, with the project file that holds the project's own variables. A record of what KiCad shows for each text; the reader does not resolve most of them yet (it replaces only ${REFERENCE} and ${VALUE} in footprint texts).

Made with KiCad 10.0.8 (file version 20260206) by fixtures/kicad/build_k10_boards.py and fixtures/kicad/add_text_vars.py (which writes k10-text-vars.kicad_pro). What KiCad shows was read back with fixtures/kicad/shown_texts.py (KiCad's GetShownText, the board loaded with its project). KiCad shows coordinates in millimeters with Y pointing down; the board's top-left corner is at page position (100, 100), and every number below is relative to that corner (so add 100 to x and y for the page position). The reader gives Y up: model x = 100 + X, model y = -(100 + Y).

Where the values live:
- In the board file: the title block (title "Text Variables", rev "B2", company "Dutchman Test", date "2026-11-27", comment 1 "First comment", comment 2 "Second comment") and one board property, BOARD_NOTE = "board property".
- In k10-text-vars.kicad_pro only: the project's text variables PCB_NUMBER = "DN-0042", BOARD_ID = "${PCB_NUMBER}-${REVISION}" (a variable that uses others) and FINISH = "ENIG" (not used by any text). With the board loaded without its project, KiCad shows ${PCB_NUMBER} and ${BOARD_ID} as they are; every other text shows the same as below.

Geometry:
- Outline: rectangle (0,0) to (100,80) on Edge.Cuts, line width 0.1; thickness 1.6.
- Board texts: 1.5 mm high, pen 0.2, left-justified, vertically centered, not turned. Rows 1 to 18 on F.SilkS at x = 5, y = 5, 8, 11, ... (row n at y = 2 + 3n); row 19 on F.Cu at (5, 59); row 20 on B.SilkS, mirrored, at (45, 75).
- Footprint test:Conn J1 on the top at (70,20), value CONN-2, user field MPN = "ABC-123" (on F.SilkS, shown, at the footprint's origin); footprint J2 flipped to the bottom at (70,50), value CONN-3, MPN = "XYZ-9" (on B.SilkS, shown). Reference fields on the silkscreen at the footprint's origin, Value fields on the Fab layer. Each has six user texts (1.5 mm, pen 0.2, left-justified) at (0, 4), (0, 7), (0, 10), (0, 13), (0, 16), (0, 19) from its origin (Y down; on J2 mirrored with the flip, so at Y = 50 + those on the page too).
